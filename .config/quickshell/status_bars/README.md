# Quickshell status bar

Панель автоматически переключается между Flexoki Dark и Flexoki Light по значению `org.gnome.desktop.interface color-scheme`. Изменение применяется реактивно на обоих мониторах без перезапуска Quickshell.

Нативный `SystemTray` отображается перед батареей на обоих мониторах: ЛКМ активирует приложение, ПКМ открывает его меню, СКМ вызывает secondary action, колесо передаётся приложению.

Базовая панель для Niri на Quickshell 0.3.x.

## Запуск

```bash
qs -p ~/.config/quickshell/status_bars/shell.qml
```

## Пользовательский сервис systemd

Готовый unit-файл находится в общей директории сервисов Quickshell:

```text
~/.config/quickshell/services/quickshell_status_bars.service
```

Установка в системный каталог пользовательских unit-файлов:

```bash
sudo install -Dm644 \
  ~/.config/quickshell/services/quickshell_status_bars.service \
  /usr/lib/systemd/user/quickshell_status_bars.service
```

Перед первым запуском сервиса завершите вручную запущенную панель, чтобы не получить два экземпляра:

```bash
qs kill -p ~/.config/quickshell/status_bars/shell.qml
systemctl --user daemon-reload
systemctl --user enable --now quickshell_status_bars.service
```

Проверка:

```bash
systemctl --user status quickshell_status_bars.service --no-pager
journalctl --user -u quickshell_status_bars.service -b --no-pager
```

В `~/.config/niri/includes/startup.kdl` закомментируйте или удалите старую строку запуска status bar:

```kdl
// spawn-sh-at-startup "qs -p ~/.config/quickshell/status_bars/shell.qml"
```

Строку запуска `lang_switch` оставьте без изменений — это отдельная конфигурация Quickshell.

## Модули

- слева: Arch launcher (`fuzzel`), workspaces Niri и MPRIS;
- по центру: текущие дата и время;
- справа: CPU, RAM, раскладка Niri, PipeWire (звук и микрофон), NetworkManager, Bluetooth, power-profiles-daemon, SystemTray и батарея UPower.

При наведении CPU показывает текущую загрузку и load average за 1/5/15 минут. RAM показывает использованную, общую и доступную память в GiB. ЛКМ по CPU или RAM открывает `btop` в полноэкранном окне Kitty.

MPRIS показывает активный плеер и текущий трек. ЛКМ переключает play/pause, средняя кнопка — предыдущий трек, ПКМ открывает меню выбора плеера.

ЛКМ по звуку или микрофону открывает `pulsemixer` в Kitty, СКМ включает/выключает mute, а колесо меняет громкость. При наведении на любой из этих модулей открывается соответствующий интерактивный ползунок: можно нажать на шкалу или перетаскивать бегунок. ЛКМ по сети открывает `nmtui` в Kitty, по Bluetooth — `bluetui`; СКМ по Bluetooth включает и выключает адаптер. Профиль питания переключается по кругу.

### Подсказки при наведении

Наведение на сеть или Bluetooth показывает подсказку с текущим подключением. Подсказка скрывается, пока открыто меню по ПКМ.

- **Сеть** — `Wi-Fi: <SSID>`, сила сигнала, тип защиты и IP-адрес; при кабеле — имя устройства, скорость линка и IP; иначе «Нет подключения».
- **Bluetooth** — список подключённых устройств с зарядом батареи, либо «Нет подключённых устройств» / «Выключен».

IP-адрес `Quickshell.Networking` не предоставляет (в `device.address` лежит MAC), поэтому он запрашивается разово через `ip -j -4 addr show <устройство>` при наведении курсора и при смене активного устройства.

Все подсказки в панели рисует общий компонент `Tooltip.qml`: ширина и высота подбираются по содержимому, поэтому многострочные подсказки (CPU, RAM, сеть) не обрезаются.

Закреплённый плеер хранится в `shell.qml` как `dbusName`, а не как ссылка на объект: строку не приходится чинить при выходе плеера, и она переживает его перезапуск, если имя шины стабильно (у Spotify это `org.mpris.MediaPlayer2.spotify`, у Firefox имя содержит номер инстанса и после перезапуска меняется — закрепление тогда возвращается к автовыбору). Состояние лежит в `ShellRoot`, а не в `Bar`, чтобы выбор был общим для всех мониторов.

### Меню по ПКМ

ПКМ по MPRIS, звуку, микрофону, сети или Bluetooth открывает меню в стиле Flexoki. Меню закрывается через 400 мс после того, как курсор ушёл и с модуля, и с самого меню.

- **MPRIS** (`MprisMenu.qml`) — список запущенных плееров с названием текущего трека, у играющего `▶`. Клик закрепляет плеер: панель показывает и управляет именно им, пока он запущен. Пункт «Автовыбор» возвращает поведение по умолчанию — первый играющий, иначе первый в списке. Последней строкой «Следующий трек» (появляется, только если плеер это умеет); меню при этом не закрывается.

- **Звук и микрофон** (`AudioDeviceMenu.qml`) — список устройств PipeWire, отметка `●` у текущего, последней строкой `pavucontrol`.
- **Сеть** (`NetworkMenu.qml`) — проводные устройства с состоянием кабеля, тумблер Wi-Fi и список точек доступа: подключённая сверху, затем известные, затем по убыванию сигнала. У защищённых сетей показан замок и сила сигнала. Клик по известной сети подключает, по подключённой — отключает, по незнакомой защищённой — открывает поле ввода пароля (Enter подключает, Esc отменяет). Пока меню открыто, работает сканирование эфира. Последней строкой `nmtui`.
- **Bluetooth** (`BluetoothMenu.qml`) — тумблер адаптера и сопряжённые устройства, подключённые сверху. Клик подключает или отключает, `◐` показывает переход, справа — заряд батареи, если BlueZ его отдаёт. Последней строкой `bluetui`.

Строки меню рисует общий делегат `DeviceRow.qml`.

### Источники данных

Звук — `Quickshell.Services.Pipewire`, Bluetooth — `Quickshell.Bluetooth` (BlueZ), сеть — `Quickshell.Networking` (NetworkManager). Опроса `nmcli` по таймеру нет: состояние приходит реактивно по DBus.

Иконка сети выбирается по типу устройства, а не по имени соединения: кабель имеет приоритет над Wi-Fi, поэтому при подключении по Ethernet или USB-тетерингу показывается иконка Ethernet даже при активном Wi-Fi.

При заряде 16–30% аккумулятор каждые 500 мс переключается между оранжевым фоном с тёмным текстом и тёмным фоном с оранжевым текстом. При критическом заряде 0–15% он каждые 380 мс переключается между красным фоном с тёмным текстом и тёмным фоном с красным текстом. Во время зарядки и выше 30% мигание отключено.
