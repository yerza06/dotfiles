# Quickshell Clipboard Menu

Замена связки `cliphist list | rofi -dmenu | cliphist decode | wl-copy` на Quickshell. Меню истории буфера обмена в теме Flexoki — той же, что у status bar, уведомлений, лаунчера и меню питания: цвета переключаются между Flexoki Light и Dark по `org.gnome.desktop.interface color-scheme`.

Хранилище истории остаётся прежним — `cliphist`. Его наполняют те же демоны из `niri/includes/startup.kdl`:

```kdl
spawn-sh-at-startup "wl-paste --type text --watch cliphist store &"
spawn-sh-at-startup "wl-paste --type image --watch cliphist store &"
```

Меню только читает базу и действует по ней, поэтому история общая с любым другим клиентом cliphist.

## Возможности

- Список записей слева, полное содержимое выбранной — справа. Собственное превью cliphist обрезано до 100 символов, так что без правой панели многострочный текст не виден.
- Миниатюры картинок прямо в списке и картинка целиком в панели превью.
- Картинки копируются с правильным MIME (`wl-copy --type image/png`). Старый rofi-пайп этого не делал, и картинка уезжала в буфер как текст.
- Поиск по строке превью: точное совпадение → префикс → начало слова → подстрока. Подпоследовательности намеренно нет — на свободном тексте она матчит почти всё.
- Закрепление: закреплённые записи всегда сверху и хранят собственную копию содержимого, поэтому переживают и вытеснение по лимиту в 750 записей, и `cliphist wipe`.
- Удаление одной записи и очистка всей истории (с подтверждением).
- Меню открывается на том мониторе, который сейчас в фокусе (`niri msg focused-output`).

## Управление

| Клавиша | Действие |
| --- | --- |
| текст | фильтрация |
| `↑` `↓` | запись вверх/вниз |
| `PageUp` / `PageDown` | восемь записей |
| `Tab` / `Shift+Tab` | следующий/предыдущий раздел |
| `Ctrl+←` / `Ctrl+→` | то же самое стрелками |
| `Enter` | скопировать в буфер и закрыть |
| `Ctrl+P` | закрепить / открепить |
| `Shift+Del` | удалить запись из истории |
| `Ctrl+Shift+Del` | очистить всю историю (спросит подтверждение) |
| `Esc` или клик мимо окна | закрыть |

`←` и `→` без модификаторов не перехватываются — они остаются за редактированием строки поиска.

Enter только кладёт запись в буфер обмена; вставка — обычным `Ctrl+V`, как и раньше с rofi.

## Разделы

| Вкладка | Что показывает |
| --- | --- |
| Всё | закреплённые, затем вся остальная история |
| Текст | только текстовые записи |
| Картинки | только изображения |
| Закреплённые | только закреплённые |

Число рядом с вкладкой — сколько записей в разделе, число справа в шапке — сколько осталось после фильтра.

## Закрепление

Закреплённые записи лежат в `~/.local/state/quickshell/by-shell/<id>/pins.json` вместе с содержимым: текст — целиком в самом файле, картинка — отдельным файлом в `~/.cache/quickshell/by-shell/<id>/pins/`. Поэтому закреплённое остаётся доступным, даже когда cliphist уже забыл исходную запись. Открепление удаляет и сохранённую копию картинки.

## Картинки

QML не умеет читать картинку из stdout, поэтому каждое изображение сначала распаковывается в файл: `~/.cache/quickshell/by-shell/<id>/thumbs/<id>-<размер>.<ext>`. Распаковка ленивая и строго по одной за раз — история держит около трёх десятков картинок, и запускать их параллельно незачем. Размер в имени файла страхует от совпадения id после `cliphist wipe`, когда счётчик начинается заново. Каталог миниатюр очищается вместе с историей.

## Производительность

`cliphist list` читается только при открытии меню, а не постоянно: при лимите в 750 записей это около 75 КБ текста на базе в сотню мегабайт. Содержимое для правой панели декодируется отдельно, с задержкой 80 мс (чтобы зажатая стрелка не плодила процессы) и обрезкой в пайпе (`head -c 16384`) — отдельные записи в базе весят мегабайты, и рендер такой целиком подвесил бы UI.

## Запуск

Меню работает как демон и показывается по IPC — так открытие происходит мгновенно, без старта процесса на каждое нажатие.

```bash
qs -c buffermenu
```

Автозапуск через systemd:

```bash
ln -sf ~/.config/quickshell/services/quickshell_buffermenu.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now quickshell_buffermenu.service
```

## IPC

```bash
qs -c buffermenu ipc call clipboard toggle         # показать/скрыть
qs -c buffermenu ipc call clipboard open           # показать
qs -c buffermenu ipc call clipboard close          # скрыть
qs -c buffermenu ipc call clipboard search docker  # показать с готовым запросом
```

Бинд в Niri (`~/.config/niri/includes/binds.kdl`):

```kdl
Mod+V hotkey-overlay-title="Clipboard: quickshell" { spawn "qs" "-c" "buffermenu" "ipc" "call" "clipboard" "toggle"; }
```

## Структура

| Файл | Назначение |
| --- | --- |
| `shell.qml` | IPC-обработчик, определение активного монитора, корень |
| `ClipboardMenu.qml` | окно-оверлей: строка поиска, вкладки, список, футер, клавиши |
| `ClipRow.qml` | строка списка |
| `ClipPreview.qml` | правая панель с полным содержимым |
| `ConfirmDialog.qml` | подтверждение очистки истории |
| `Clips.qml` | чтение cliphist, ранжирование, копирование, удаление, закрепления, миниатюры |
| `Theme.qml` | палитра Flexoki и отслеживание светлой/тёмной темы |
