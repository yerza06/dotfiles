# Quickshell Power Menu

Замена `~/.config/rofi/scripts/powermenu.sh` на Quickshell. Меню питания в теме Flexoki — той же, что у status bar, уведомлений и лаунчера: цвета переключаются между Flexoki Light и Dark по `org.gnome.desktop.interface color-scheme`, без перезапуска процесса.

## Возможности

- Шесть действий в один ряд: Выключить, Перезагрузить, Сон, Hibernate, Заблокировать, Выйти. Команды те же, что были в rofi-скрипте.
- У каждого действия свой акцент Flexoki, который загорается на выбранной плитке: красный, жёлтый, циан, синий, зелёный, фиолетовый.
- Выключение, перезагрузка и hibernate спрашивают подтверждение — карточка не меняет размер, ряд плиток заменяется на «Выключить компьютер? Нет / Да». Преднабрано **«Нет»**.
- В шапке — uptime, посчитанный из `/proc/uptime` (текст русский независимо от локали), обновляется при каждом открытии.
- Выделение мышью включается только после реального движения курсора: меню, всплывшее под неподвижной мышью, не преднабирает случайную плитку и тем более «Да».
- Меню открывается на том мониторе, который сейчас в фокусе (`niri msg focused-output`).

## Управление

| Клавиша | Действие | В диалоге подтверждения |
| --- | --- | --- |
| `←` `→` | предыдущая/следующая плитка | между «Нет» и «Да» |
| `Tab` / `Shift+Tab` | то же | то же |
| `Home` / `End` | первая/последняя плитка | — |
| `1`…`6` | сразу выбрать и выполнить | — |
| `Enter` | выполнить действие | подтвердить выбранное |
| `Esc` или клик мимо окна | закрыть | отменить, вернуться к плиткам |

## Запуск

Меню работает как демон и показывается по IPC — так открытие происходит мгновенно, без старта процесса на каждое нажатие.

```bash
qs -c powermenu
```

Запускать нужно именно через `-c powermenu`: синглтоны `Theme` и `Actions` авторегистрируются по имени конфига.

Автозапуск через systemd:

```bash
ln -sf ~/.config/quickshell/services/quickshell_powermenu.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now quickshell_powermenu.service
```

## IPC

```bash
qs -c powermenu ipc call power toggle   # показать/скрыть
qs -c powermenu ipc call power open     # показать
qs -c powermenu ipc call power close    # скрыть
```

Бинд в Niri (`~/.config/niri/includes/binds.kdl`):

```kdl
Mod+Delete hotkey-overlay-title="Power Menu: quickshell" { spawn "qs" "-c" "powermenu" "ipc" "call" "power" "toggle"; }
```

Старая строка с rofi оставлена рядом закомментированной — скрипт и `powermenu.rasi` никуда не делись и работают как запасной вариант.

## Структура

| Файл | Назначение |
| --- | --- |
| `shell.qml` | IPC-обработчик, определение активного монитора, корень |
| `PowerMenu.qml` | окно-оверлей: шапка, ряд плиток, футер, клавиши, режим подтверждения |
| `PowerTile.qml` | плитка действия |
| `ConfirmDialog.qml` | подтверждение деструктивных действий |
| `Actions.qml` | список действий с командами, запуск, uptime |
| `Theme.qml` | палитра Flexoki и отслеживание светлой/тёмной темы |
