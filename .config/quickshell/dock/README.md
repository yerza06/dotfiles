# Quickshell Dock

Плавающий автоскрывающийся dock для Niri на Quickshell 0.3.x. На каждом мониторе показываются закреплённые приложения и незакреплённые приложения с окнами на этом экране. Оформление автоматически переключается между Flexoki Light и Dark по `org.gnome.desktop.interface color-scheme`.

## Возможности

- крупная капсула Floating Flexoki с мягкой тенью и без резервирования рабочей области;
- раскрытие при наведении на центральную область нижнего края и скрытие после ухода курсора;
- мягкая «волна» иконок: 48 px, 53 px у соседней и 58 px под курсором;
- группировка окон через `ToplevelManager`, запуск и иконки через `DesktopEntries`;
- отдельный набор запущенных приложений для каждого монитора;
- сохранение закреплений и их порядка в состоянии Quickshell;
- Flexoki Light/Dark без зависимости от blur композитора.

При первом запуске закреплены Kitty, Firefox, Sendoff и Spotify. Если соответствующий desktop-entry временно отсутствует, его идентификатор сохраняется и значок вернётся после установки приложения.

## Управление

| Действие | Результат |
| --- | --- |
| Навести на нижнюю центральную зону | показать dock |
| ЛКМ по незапущенному приложению | запустить приложение |
| ЛКМ по запущенному приложению | активировать или циклически переключить его окна |
| Средняя кнопка | открыть новый экземпляр |
| ПКМ | показать окна и действия приложения |
| Перетащить закреплённую иконку | изменить сохранённый порядок |

В меню доступны выбор конкретного окна, «Новое окно», «Закрепить/Убрать» и «Закрыть все окна». Для неизвестного `appId` остаются активация и закрытие окон, но запуск и закрепление недоступны.

## Запуск

```bash
qs -c dock
```

Автозапуск через systemd:

```bash
ln -sf ~/.config/quickshell/services/quickshell_dock.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now quickshell_dock.service
```

## Структура

| Файл | Назначение |
| --- | --- |
| `shell.qml` | экземпляр `Dock` для каждого экрана |
| `Dock.qml` | окно панели, автоскрытие, input mask и секции приложений |
| `DockItem.qml` | иконка, индикаторы, hover-анимация и drag-and-drop |
| `DockMenu.qml` / `DockTooltip.qml` | контекстное меню и подсказка |
| `DockModel.qml` | окна, desktop-entry, сохранение pins и действия |
| `DockLogic.js` | тестируемая логика группировки, порядка и циклического выбора |
| `Theme.qml` | Flexoki Light/Dark |
