# Quickshell Emoji Menu

Палитра эмодзи, юникод-символов, каомодзи и иконок Nerd Font на Quickshell — замена GTK-эмодзи-панели и походов в браузер за символом. Тема Flexoki, та же, что у status bar, уведомлений, лаунчера, меню питания и меню буфера: цвета переключаются между Flexoki Light и Dark по `org.gnome.desktop.interface color-scheme`.

Оформление взято у `buffermenu` (оверлей, карточка, поиск, вкладки), а раскладка — у `menu_applications`: символы выложены сеткой плиток, а не списком. Для палитры это правильнее — глиф важнее подписи, и на экран влезает вчетверо больше.

Набор символов статический и лежит рядом с конфигом:

```bash
python3 ~/.config/quickshell/emojimenu/scripts/gen-glyphs.py
```

## Возможности

- Четыре набора в одном окне: 1 384 эмодзи, 2 548 юникод-символов, 77 каомодзи и 10 403 иконки Nerd Font — 14 412 записей.
- Сетка плиток с ленивой отрисовкой: видно 40–50 символов сразу, модель на четырнадцать тысяч записей рендерит только видимые ряды.
- Двухуровневые вкладки: раздел сверху, подраздел под ним. Эмодзи разложены по официальным группам UTS #51 (смайлы, люди, природа, еда, места, занятия, предметы, знаки, флаги), символы — по типу (стрелки, математика, рамки, валюты…), иконки — по набору (`md`, `fa`, `dev`, `cod`, `oct`…).
- Набор собирается офлайн из уже установленного: имена символов берутся из `unicodedata` (UCD 16.0), группы эмодзи — из официального `emoji-test.txt` (UTS #51, Emoji 17.0), иконки — из таблицы `cmap` шрифта Symbols Nerd Font через `fontTools`. В рантайме внешних зависимостей нет вообще: ни процессов, ни сети.
- Поиск: точное совпадение → префикс → начало слова → подстрока → подпоследовательность. В отличие от меню буфера подпоследовательность здесь нужна — имена короткие и курируемые, так что `arrw` находит `rightwards arrow`. На запросах короче трёх букв она отключается, иначе совпадёт весь набор.
- Официальные имена Unicode местами далеки от того, что набирают в поиске (`❤` — «heavy black heart»), поэтому у ходовых символов есть синонимы: `heart`, `thumbsup`, `shrug`, `check`, `tada`, `wip`.
- «Частые» — счётчик вставок, вкладка сортируется по нему. Ничего помечать вручную не нужно, и меню открывается сразу на ней.
- «Закреплённые» — ручной отбор поверх счётчика. Пин хранит собственную копию полей, поэтому переживает перегенерацию набора.
- Символ уходит в буфер напрямую (`Quickshell.clipboardText`), без `wl-copy` и вообще без порождения процессов.
- Меню открывается на том мониторе, который сейчас в фокусе (`niri msg focused-output`).

## Управление

| Клавиша | Действие |
| --- | --- |
| текст | фильтрация |
| `↑` `↓` | ряд вверх/вниз |
| `Ctrl+←` / `Ctrl+→` | символ влево/вправо |
| `PageUp` / `PageDown` | три ряда |
| `Tab` / `Shift+Tab` | следующий/предыдущий подраздел |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | следующий/предыдущий раздел |
| `Enter` | скопировать в буфер и закрыть |
| `Ctrl+P` | закрепить / открепить |
| `Shift+Del` | забыть символ (убрать из «Частых») |
| `Ctrl+Shift+Del` | очистить всю историю частых (спросит подтверждение) |
| `Esc` или клик мимо окна | закрыть |

Голые `←` и `→` не перехватываются — они остаются за редактированием строки поиска, поэтому движение по символам вынесено на `Ctrl`. Вверх-вниз с правкой строки не конфликтуют и работают без модификатора.

`Shift+Del` не удаляет символ: он часть набора, а не запись истории. Сбрасывается только счётчик вставок. Подсказка про него и про очистку показывается в подвале только во вкладке «Частые» — в остальных разделах забывать нечего.

Enter только кладёт символ в буфер обмена; вставка — обычным `Ctrl+V`.

## Разделы

| Вкладка | Что показывает |
| --- | --- |
| Частые | всё, что уже вставляли, по убыванию счётчика |
| Закреплённые | отобранное вручную через `Ctrl+P` |
| Всё | весь набор целиком |
| Эмодзи | 1 384 настоящих эмодзи, 9 подразделов |
| Символы | 2 548 знаков, 13 подразделов |
| Каомодзи | `¯\_(ツ)_/¯`, `ಠ_ಠ`, `(╯°□°）╯︵ ┻━┻` и прочий ASCII-арт |
| Иконки | 10 403 глифа Nerd Font, 12 подразделов по наборам |

Полоса подразделов появляется только там, где делить есть что: у «Частых», «Закреплённых», «Всего» и каомодзи её нет. У «Символов» и «Иконок» подразделов больше, чем влезает в ширину карточки, поэтому полоса прокручивается по горизонтали.

Число рядом с вкладкой — сколько записей в разделе, число справа в шапке — сколько осталось после фильтра. Справа в подвале — имя выбранного символа, его кодпоинт и счётчик вставок; отдельной панели превью в сеточной раскладке нет.

Меню открывается на «Частых», а пока их нет — на «Эмодзи»: список «Всё» на четырнадцати тысячах записей сам по себе бесполезен. Фильтр по подразделу сбрасывается при каждом открытии.

## Набор символов

`data/glyphs.json` (1,4 МБ) собирается скриптом `scripts/gen-glyphs.py` и коммитится в репозиторий — пересобирать его при установке не нужно. Скрипту требуются только `python3` и `fontTools`; путь к шрифту берётся через `fc-match`, а не хардкодится.

Каждая запись — шесть полей: символ, имя, строка для поиска, раздел, подраздел и кодпоинт. Строка поиска приведена к нижнему регистру на этапе генерации, поэтому ранжирование четырнадцати тысяч записей на каждое нажатие обходится без единого `toLowerCase()`.

Эмодзи отбираются строго по официальному списку UTS #51, а не по диапазонам кодпоинтов. Это важно: в «эмодзи-блоках» Unicode лежит около тысячи пиктограмм, которые эмодзи не являются — маджонг, игральные карты, дингбаты, часть Misc Symbols. Раньше они засоряли раздел «Эмодзи»; теперь проваливаются в «Символы», в подразделы «Игральные» и «Пиктограммы».

Подразделы иконок берутся из префиксов имён глифов. Наборы меньше десяти иконок собственной вкладки не получают и сводятся в «Прочее» — иначе в полосе оказывалось восемь вкладок по одной иконке.

Вывод детерминирован: ни таймстампов, ни путей внутри, поэтому повторный запуск даёт побайтово тот же файл и не мусорит в диффах.

Чего в наборе нет: флагов стран. Они собираются парами regional indicators, а названий стран `unicodedata` не даёт — подписывать их пришлось бы вручную. Общие флаги (🏁 🏳 🏴 🚩 🎌) на месте. Не вошли также модификаторы тона кожи, селекторы начертания и прочее, что осмысленно только внутри последовательности.

## Частые и закреплённые

Счётчик вставок лежит в `~/.local/state/quickshell/by-shell/<id>/usage.json`, закрепления — в `pins.json` рядом. Запись счётчика отложена на 400 мс, чтобы серия вставок подряд не била по диску на каждое нажатие.

Пин хранит копию всех полей символа, а не ссылку на набор. Поэтому закреплённое продолжает работать, даже если после перегенерации `glyphs.json` символ из набора исчезнет. В плитке закреплённое помечается уголком — на подпись места нет.

## Шрифты

Iosevka не рисует цветные эмодзи, а Noto Color Emoji не знает приватную зону Nerd Font, поэтому семейство выбирается по разделу записи: эмодзи — `Noto Color Emoji`, иконки — `Symbols Nerd Font`, всё остальное — `IosevkaTerm Nerd Font Propo`. Каомодзи не помещаются в поле под один глиф, так что в плитке они рисуются мелко и с переносом на две строки.

## Запуск

Меню работает как демон и показывается по IPC — так открытие происходит мгновенно, без старта процесса на каждое нажатие.

```bash
qs -c emojimenu
```

Форма `-c emojimenu` обязательна: синглтоны `Theme` и `Glyphs` регистрируются по имени конфига, с `-p <путь>` они не поднимутся.

Автозапуск через systemd:

```bash
ln -sf ~/.config/quickshell/services/quickshell_emojimenu.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now quickshell_emojimenu.service
```

## IPC

```bash
qs -c emojimenu ipc call emoji toggle          # показать/скрыть
qs -c emojimenu ipc call emoji open            # показать
qs -c emojimenu ipc call emoji close           # скрыть
qs -c emojimenu ipc call emoji search rocket   # показать с готовым запросом
```

Бинд в Niri (`~/.config/niri/includes/binds.kdl`):

```kdl
Mod+Period hotkey-overlay-title="Emoji Picker: quickshell" { spawn "qs" "-c" "emojimenu" "ipc" "call" "emoji" "toggle"; }
```

`Mod+Period` до этого был занят под `expel-window-from-column`; команда переехала на `Mod+Shift+Period`, парный ей `Mod+Comma` не тронут.

## Структура

| Файл | Назначение |
| --- | --- |
| `shell.qml` | IPC-обработчик, определение активного монитора, корень |
| `EmojiMenu.qml` | окно-оверлей: строка поиска, вкладки, подвкладки, сетка, подвал |
| `EmojiTile.qml` | плитка одного символа |
| `KeyNavigation.js` | раскладка навигации по сетке, чистая функция без состояния |
| `ConfirmDialog.qml` | подтверждение очистки частых |
| `Glyphs.qml` | загрузка набора, разделы, ранжирование, копирование, счётчик, закрепления |
| `Theme.qml` | палитра Flexoki и отслеживание светлой/тёмной темы |
| `scripts/gen-glyphs.py` | офлайн-сборка набора из `unicodedata`, `emoji-test.txt` и Symbols Nerd Font |
| `data/glyphs.json` | сам набор, коммитится в репозиторий |
